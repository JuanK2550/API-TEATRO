# Créditos de las imágenes

Fotografías de [Unsplash](https://unsplash.com), bajo la
[Licencia de Unsplash](https://unsplash.com/license): uso libre, también comercial,
sin pedir permiso. El crédito no es obligatorio, pero se incluye.

Están descargadas dentro del proyecto y convertidas a WebP en dos anchos, 1800 px y
900 px, recortadas a 3:2. **Se muestran a todo color**: el duotono de telón y oro
que se usaba antes volvía marrón cualquier fotografía y se quitó en el rediseño.
Lo único que se les aplica por CSS es un punto de saturación y contraste, y un
velo oscuro donde se apoya el texto para que se lea. El archivo no se retoca.

## Fotografías del rediseño

Las siguientes se añadieron al rediseñar la Sala. Vienen del mismo sitio y la
misma licencia, pero aquí hay que ser honestos: **no fue posible resolver el
nombre del fotógrafo**. Se descargaron por la dirección directa del CDN de
Unsplash, y esa dirección no permite llegar a la página de la foto ni a su
autoría. La Licencia de Unsplash no exige el crédito, así que el uso es
correcto, pero el crédito por nombre que sí tienen las de arriba no se pudo
completar. Queda la dirección exacta de origen, que identifica cada foto sin
ambigüedad.
