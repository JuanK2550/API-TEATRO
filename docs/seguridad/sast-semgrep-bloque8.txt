desactivo esa proteccion: se uso el contenedor.

    semgrep scan --config=p/javascript --config=p/nodejs \
    --config=p/owasp-top-ten --metrics=off --no-git-ignore \
    --exclude=node_modules --exclude=.git \
    src scripts frontend pruebas
