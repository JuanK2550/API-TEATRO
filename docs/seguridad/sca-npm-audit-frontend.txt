==============================================================
Por qué no se corrige
==============================================================
El aviso GHSA-vfj7-8cjw-p6xm afecta a braces en el rango *, es decir a todas
sus versiones publicadas: no hay versión corregida a la que actualizar. Ya
está instalada la última, braces 3.0.3.

La cadena es nodemon -> chokidar -> braces, y nodemon es devDependency: solo
se usa con 'npm run dev'. Por eso 'npm audit --omit=dev' da 0.

Intentos, en orden:
  a) npm audit fix          -> no cambia nada, no hay versión a la que subir
  b) overrides en package.json -> descartado: no existe braces corregido
  c) documentarlo           -> esta es la opción aplicada

npm audit fix --force bajaría nodemon a 1.14.10, nueve versiones mayores
atrás, y se descartó.
